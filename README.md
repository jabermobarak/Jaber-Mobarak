# Hi, I'm Jaber Mobarak

I'm a master's student in AI & Big Data at STANKIN in Moscow.
My interests include computer vision, multimodal learning, and
reliable evaluation of AI systems.

### Current research
My master's thesis investigates failure modes in vision-language
models for medical image understanding. I work with Qwen2.5-VL
and VQA-RAD, examining both model responses and the reliability
of automated evaluation.

This research is ongoing; independent validation is still in progress.

### Selected projects
- [Assistive Vision Mobile App](https://github.com/jabermobarak/Be-My-Eyes):
  Flutter application combining MobileNet image classification
  with spoken feedback.
- [Assistive Camera Prototype](https://github.com/jabermobarak/Computer_vision_Glasses_for_blind_people):
  Python application combining camera input, object recognition,
  OCR, and text-to-speech.
- [Question Answering](https://github.com/jabermobarak/Question-Answering):
  Flask application using pretrained RoBERTa to extract answers
  from user-provided text.
